# 02 — 角色与成长系统

> 文档族：doc v3.0

---

## 1. 烙印 = 创角天赋（永久职业方向）

创角时选择 **1** 个烙印系。烙印决定：

- 可装备的**武器类型池**
- 可学习的**技能树**
- 身板倾向（厚血自愈 / 脆皮机动 / 清场 / 召唤）
- 部分衍生属性权重（战痕吃力量 / 体力，鹰眼吃敏捷，元素吃智力，亲和吃精神）

烙印**不可**在局内随机更换；若未来开放转职，须高成本材料 + 城镇仪式（后置，不进 MVP）。

武器栏仍是装备槽之一，但必须属于本烙印系。游戏内角色模型按 **持有武器** 换整张 8 向表，武器画进角色本体，不另挂独立武器精灵。

### 1.1 战痕烙印

近战力量流。可用：刀、斧、剑、锤。强调自身力量，抗打、自愈。

| 武器 | 手感倾向 |
|------|----------|
| 刀 | 攻速快，连斩，可挂流血 |
| 斧 | 高硬直 / 破韧，挥空重 |
| 剑 | 均衡，判定清晰 |
| 锤 | 破盾特化，慢而重 |

创角倾向：+2 力量、+2 体力；生命 ×1.25；物防 +2；固有生命回复与少量命中吸血。

MVP：**仅刀**。斧 / 剑 / 锤后置（换模接口先留：`held_weapon` → 8 向表）。

### 1.2 鹰眼烙印

远程单体流。可用：弓、弩、矛。身板灵活但脆。

| 武器 | 手感倾向 |
|------|----------|
| 弓 | 中远点射，走位与蓄力 |
| 弩 | 更慢更重的单体贯穿 |
| 矛 | 投掷直线，近中距高伤 |

创角倾向：+2 敏捷；生命 ×0.80；物防 −1；移速 +12%。

箭矢为消耗品（材料合成或商店购买）后置。MVP 后置本系完整操作；默认持弓模型。

### 1.3 元素烙印

凝聚自然元素战斗，不另作法杖道具层。创角主修 **1** 个元素；清场强，单体略差，身板脆。

| 元素 | 核心效果 |
|------|----------|
| 冰 | 减速 / 冻结积蓄 |
| 火 | 灼烧（持续伤害） |
| 酸 | 破甲（降低物/魔防） |
| 暗 | 减攻 / 吸血或恐惧（表定） |
| 光 | 治疗 / 净化 / 对畸变体额外伤 |

创角倾向：+2 智力；生命 ×0.80；物防 −1；范围技 ×1.15，单体弹道 ×0.90。

副元素后置。MVP 后置本系完整操作。

### 1.4 亲和烙印

通过召唤物辅助自身战斗。创角亲和 **动物** 或 **植物**（只换召唤物外观与特效色，不拆两棵技能树）。自身身板脆。

- 契约槽上限挂钩 **精神** 与 **幸运**。
- 召唤物继承部分玩家属性；可被击破，冷却后重召。
- 可与秘境「特殊怪」缔约（条件苛刻，后置）。
- MVP 后置完整召唤树；最小集：1 只跟随召唤物。

创角倾向：+2 精神；生命 ×0.80；物防 −1。

## 2. 主属性（6 项）

升级获得**属性点**，由玩家分配。不可在坑内重置；城镇感悟台可付费重置（后置，MVP 不可重置）。

| 属性 | 主要影响 |
|------|----------|
| **力量** | 近战物攻、承重 |
| **敏捷** | 攻速、暴击、闪避、弓 / 弩 / 矛操控 |
| **智力** | 魔攻、元素强度、**念力上限** |
| **体力** | 生命上限、韧性（自身抗硬直 / 破盾抗性） |
| **精神** | **念力回复**、侵蚀抗性、技能持续时间 / 召唤维持 |
| **幸运** | 掉率、晶核爆率、挖矿产出、秘境察觉（小地图微光） |

### 衍生属性

物攻、魔攻、物防、魔防、暴击、爆伤、攻速、移速、闪避、念力上限、念力回复、承重上限、侵蚀抗性、召唤上限。

换算系数进数据表 `data/attributes.json`（见 `07`），禁止写死在战斗脚本。

### 初始值（初表，可调）

每项主属性基础 **10**。创角按烙印给倾向（战痕 +2 力量 / 体力，鹰眼 +2 敏捷，元素 +2 智力，亲和 +2 精神），并套用 §1 身板系数。MVP 刀手可只开放力量 / 体力显示，其余占位。

## 3. 等级与经验

| 项 | 定案 |
|----|------|
| 来源 | **击杀怪物**、**完成任务**（交付时结算 XP） |
| 挖矿 / 采集 | 默认不给 XP（避免挂机挖矿升级） |
| 入账 | 击杀立即入账；任务 XP 在交付时结算 |
| 死亡 | XP **不回退** |
| 升级奖励 | **属性点**（初表：每级 **3** 点）+ 微量生命成长（表定，可调为 0） |

- **废弃**独立「念力等级」元进度。原「念力等级门槛」改由 **角色等级 + 晶核品阶** 承担。
- 升级曲线进 `data/xp_curve.json`。现行代码 `40 + lv * 25`、等级上限 30 仅作占位，冻结后改表。

### 与念力的关系

- 念力是**战斗 / 传送资源**，不是第二套等级。
- 智力提高念力上限；精神提高回复；休息回满（见 `03`）。

## 4. 角色面板展示结构

- **基础资源**：生命、念力（当前 / 上限）、侵蚀度、角色等级 / XP、未分配属性点
- **主属性**：力量、敏捷、智力、体力、精神、幸运
- **进阶**：暴击、爆伤、攻速、闪避、侵蚀抗性
- **攻防**：物攻、魔攻、物防、魔防
- **装备栏**：见 `04`（武器受烙印限制）
- **烙印**：系名 + 当前武器类型（`held_weapon`）

MVP 实装子集：生命、念力、等级/XP、属性点、力量、体力、物攻、物防；其余可占位隐藏。
