# 02 — 角色与成长系统

> 文档族：doc v3.0

---

## 1. 烙印 = 创角天赋（永久职业方向）

创角时选择 **1** 个烙印系。烙印决定：

- 可装备的**武器类型池**
- 可学习的**技能树**
- 部分衍生属性权重（如热武吃敏捷 / 力量，法杖吃智力）

烙印**不可**在局内随机更换；若未来开放转职，须高成本材料 + 城镇仪式（后置，不进 MVP）。

武器栏仍是装备槽之一，但必须属于本烙印系。

### 1.1 冷兵器烙印

可用：刀、斧、剑、锤、矛、弓。

| 武器 | 手感倾向 |
|------|----------|
| 刀 | 攻速快，连斩，可挂流血 |
| 斧 | 高硬直 / 破韧，挥空重 |
| 剑 | 均衡，判定清晰 |
| 锤 | 破盾特化，慢而重 |
| 矛 | 射程优势，突刺直线 |
| 弓 | 物理远程，需走位与蓄力 |

MVP：**仅刀**。其余武器后置。

### 1.2 热武器烙印（炼金热兵器）

设定：火药与炼金推进，**不是**现代制式军工。外观偏机关 / 铜管 / 晶石点火。

**枪类**

| 种类 | 手感倾向 |
|------|----------|
| 手枪 | 近距机动，换弹快 |
| 步枪 | 中距精准点射 |
| 冲锋枪 | 扫射，压后坐，耗弹快 |
| 霰弹枪 | 近距锥形，高爆发 |
| 机枪 | 持续火力，移速惩罚 |
| 狙击枪 | 远距蓄力，高暴击 |

**炮类**

| 种类 | 手感倾向 |
|------|----------|
| 榴弹发射器 | 抛物线爆炸，友伤警戒 |
| 迫击炮 | 落点 AoE，预判与站桩 |

弹药为消耗品（材料合成或商店购买）；MVP 后置本系。

### 1.3 魔元素烙印（法杖）

仅用法杖。按元素扩展，**核心异常不同**：

| 元素 | 核心效果 |
|------|----------|
| 冰 | 减速 / 冻结积蓄 |
| 火 | 灼烧（持续伤害） |
| 酸 | 破甲（降低物/魔防） |
| 暗 | 减攻 / 吸血或恐惧（表定） |
| 光 | 治疗 / 净化 / 对畸变体额外伤 |

同一角色主修 **1** 个元素（创角或首次感悟选定）；副元素后置。MVP 后置本系。

### 1.4 亲和力烙印（魔杖 · 召唤）

用法杖近亲：**魔杖**。通过亲和力吸引生物，签订**契约**，主打召唤流。

- 契约槽上限挂钩 **精神** 与 **幸运**。
- 召唤物继承部分玩家属性；有持续时间或维持念力。
- 可与秘境「特殊怪」缔约（条件苛刻）。
- MVP 后置本系。v2.0「不做宠物」废止，改为阶段 D 内容。

## 2. 主属性（6 项）

升级获得**属性点**，由玩家分配。不可在坑内重置；城镇感悟台可付费重置（后置，MVP 不可重置）。

| 属性 | 主要影响 |
|------|----------|
| **力量** | 近战 / 热武物攻、承重 |
| **敏捷** | 攻速、暴击、闪避、弓 / 枪操控（散布 / 换弹） |
| **智力** | 魔攻、法杖强度、**念力上限** |
| **体力** | 生命上限、韧性（自身抗硬直 / 破盾抗性） |
| **精神** | **念力回复**、侵蚀抗性、技能持续时间 / 召唤维持 |
| **幸运** | 掉率、晶核爆率、挖矿产出、秘境察觉（小地图微光） |

### 衍生属性

物攻、魔攻、物防、魔防、暴击、爆伤、攻速、移速、闪避、念力上限、念力回复、承重上限、侵蚀抗性、召唤上限。

换算系数进数据表 `data/attributes.json`（见 `07`），禁止写死在战斗脚本。

### 初始值（初表，可调）

每项主属性基础 **10**。创角按烙印给少量倾向（例：冷兵器 +2 力量，热武 +2 敏捷，法杖 +2 智力，亲和 +2 精神）。MVP 刀手可只开放力量 / 体力显示，其余占位。

## 3. 等级与经验

| 项 | 定案 |
|----|------|
| 来源 | **击杀怪物**、**完成任务**（交付时结算 XP） |
| 挖矿 / 采集 | 默认不给 XP（避免挂机挖矿升级） |
| 入账 | 击杀立即入账；任务 XP 在交付时入账 |
| 死亡 | XP **不回退** |
| 升级奖励 | **属性点**（初表：每级 **3** 点）+ 微量生命成长（表定，可调为 0） |

- **废弃**独立「念力等级」元进度。原「念力等级门槛」改由 **角色等级 + 晶核品阶** 承担。
- 升级曲线进 `data/xp_curve.json`。现行代码 `40 + lv * 25`、等级上限 30 仅作占位，冻结后改表。

### 与念力的关系

- 念力是**战斗 / 传送资源**，不是第二套等级。
- 智力提高念力上限；精神提高回复；休息回满（见 `03`）。

## 4. 角色面板展示结构

- **基础资源**：生命、念力（当前 / 上限）、侵蚀度、角色等级 / XP、未分配属性点
- **主属性**：力量、敏捷、智力、体力、精神、幸运
- **进阶**：暴击、爆伤、攻速、闪避、侵蚀抗性
- **攻防**：物攻、魔攻、物防、魔防
- **装备栏**：见 `04`（武器受烙印限制）
- **烙印**：系名 + 当前武器类型

MVP 实装子集：生命、念力、等级/XP、属性点、力量、体力、物攻、物防；其余可占位隐藏。
