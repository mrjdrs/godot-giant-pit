# 04 — 物品与经济系统

> 文档族：doc v3.0

---

## 1. 两轴：品阶 × 品质

装备、消耗品、任务物品、材料、晶核 **共用** 两轴。两轴独立，可组合（例：三品 · 史诗 胸甲）。

### 1.1 品阶（力量带）

九品最低 → 一品最高。内部 `grade` = 1～9，其中 1 = 九品，9 = 一品。

| 显示 | grade | 大致对应层级（草案） |
|------|-------|----------------------|
| 九品 | 1 | 第 1 层外围 |
| 八品 | 2 | 第 1 层 |
| 七品 | 3 | 第 1 层精英 / 秘境 |
| 六品 | 4 | 第 2 层 |
| 五品 | 5 | 第 2 层精英 |
| 四品 | 6 | 第 3 层 |
| 三品 | 7 | 深层精英 |
| 二品 | 8 | 深层领主 |
| 一品 | 9 | 终局 / 奇观 |

技能学习门槛卡的是晶核**品阶**（见 `03`）。

### 1.2 品质（稀有度）

从低到高 **6 档**（原文曾写「五种」，以本列表 6 名为准）：

| 顺序 | 名称 | 建议色（可调） |
|------|------|----------------|
| 1 | 普通 | 灰白 `#D1D1C7` |
| 2 | 精良 | 绿 `#73E085` |
| 3 | 稀有 | 蓝 `#6BADFF` |
| 4 | 传说 | 橙金 `#FFC74A` |
| 5 | 史诗 | 紫 `#C77AFF` |
| 6 | 神话 | 红焰 / 虹 `#FF5A4A` |

品质影响：词缀条数 / 数值幅度 / 分解产出 / 商店卖价。  
**不**单独替代品阶：低品阶神话仍弱于高品阶普通的基础白值，但词缀更有趣。

现行代码 `ItemTier` 五档且未分品阶，工程迁移见 `07` / `09`。

## 2. 装备系统

### 2.1 槽位

| 槽 | ID | MVP |
|----|-----|-----|
| 武器 | `weapon` | 必做（受烙印系限制） |
| 头盔 | `head` | 阶段 C |
| 胸甲 | `chest` | 阶段 C（现有胸甲可迁） |
| 护手 | `hands` | 后置 |
| 护腿 | `legs` | 后置 |
| 靴子 | `feet` | 后置 |
| 腰带 | `belt` | 后置 |
| 挂坠 | `amulet` | 阶段 C（现有挂坠可迁） |
| 戒指 | `ring1` / `ring2` | 后置 |

武器类型必须属于当前烙印系，否则无法装备。

### 2.2 磨损与修理

- 死亡：穿戴防具各 **−1 强化**（或等价磨损），不低于白板 **50%**。
- 角色等级 1～2：免磨损（新手保护，可调）。
- 修理：城镇炼金台消耗材料 + 金币（阶段 C+）。MVP 可「只降不修」。

### 2.3 打造

城镇炼金台：材料 → 白板装备（品阶由材料品阶决定，品质有权重表）。随机词缀装备雨 **不做**（与 v2.0 一致）。

## 3. 物品系统

| 大类 | 说明 | 品阶×品质 |
|------|------|-----------|
| 消耗品 | 念力药剂、生命药、箭矢（鹰眼，后置）、诱饵（钓鱼）等 | 是 |
| 任务物品 | 不可出售；可占格或独立任务栏（初表：占背包格） | 可只标品阶，品质固定普通 |
| 材料 | 怪物材料、矿、草、晶石；用于打造 / 任务 / 合成 | 是 |
| 晶核 | 学技能专用，见 `03` | 是（品阶卡学习，品质影响卖价） |

### 背包

- 默认 **10 格** + **承重**；满格或超重 → 不可拾取。
- 格子扩展：空间类消耗品（预留 ≥1 种）。
- 承重挂钩 **体力**（+ 装备 / 城镇设施）。
- 金币与道具分栏；金币是否有重量：**v3.0 默认金币无重量**（纸券减重后置，见经济）。

## 4. 经济系统

- **唯一货币：金币。**
- **杀怪不掉落金币。**
- 来源：
  - 任务交付
  - 向 NPC / 兑换所出售材料与多余装备 / 晶核
  - 宝箱（少量）
  - 钓鱼等休闲（后置，少量）
- 去向：商店药剂、修理、传送以外的服务、（后置）重置属性 / 技能。

**纸券**：v2.0 用纸券给金币减重。v3.0 金币默认无重量 → 纸券 **后置**；若恢复金币重量，再启用纸券。

## 5. 数据表字段（规范）

每条物品至少：

```text
id, name_key, icon, category,   # weapon / armor / consumable / quest / material / core
grade,                          # 1–9 品阶
quality,                        # 0–5 品质枚举
stack, weight, sell_gold,
imprint_family?, weapon_type?,  # 仅武器
armor_slot?,                    # 仅防具
use_effect?,                    # 仅消耗品
```

禁止在 `player.gd` / `inventory.gd` 写死新数值。
