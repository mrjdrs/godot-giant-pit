# 01 — 核心玩法循环系统

> 文档族：doc v3.0

---

## 1. 主循环

```text
【鹤城镇 · 静态】
  接任务 / 打造与修理 / 技能树消耗晶核 / 分配属性点
  卖物换金 / 买药剂 / 休息（念力回满）
  查看秘境传闻、已解锁锚点
        ↓
【巨坑大地图 · 按区域】
  战斗 → 怪物材料、晶核、经验（不掉金币）
  挖掘 / 挖矿 → 材料
  侵蚀随探索时间累积 → 规划深度与回城
  普通区域 + 隐藏秘境（解密或额定条件开启）
  可选：激活传送锚点（耗念力互传 / 回城）
        ↓
【成长】
  装备（品阶×品质）/ 技能（晶核品阶门槛）/ 属性点
        ↓
【再挑战】更深层级 · 更高品阶内容 · 秘境 / 领主
```

目标单次下潜体感：**30～60 分钟**可完成一次「进坑 → 有收获 → 回城养成」；角色进度跨次保留。

---

## 2. 「下潜」定义

- **进入巨坑一次 = 一次下潜**，不是肉鸽「一局清档」。
- 角色、已学技能、属性点、仓库、已解锁锚点 / 秘境 **永久保留**。
- 大地图区域可反复探索；秘境 / 部分副本为**随机实例**（每次生成可不同）。
- MVP **只做第 1 层**（1～2 个生态 + 1 个秘境入口）；第 2 层+ 仅灰态接口。

---

## 3. 死亡与回城

| 情况 | 烙印 | 已学技能 / 属性点 | 背包 | 穿戴装备 | 侵蚀 | XP |
|------|------|-------------------|------|----------|------|-----|
| 主动回城（锚点 / 坑口） | 保留 | 保留 | 全部带回 | 无额外惩罚 | 清零或大幅衰减 | 保留 |
| 死亡 | 保留 | 保留 | 全部保留（可调：现场掉 0～1 件非任务物，MVP 不掉包） | **磨损**（胸甲等 −1 强化或等价） | 清零 | 保留（不回退） |

- **不再**「自选保留 1 格」。
- 死亡复活点：最近已激活锚点，若无则鹤城镇坑口。
- 任务：未交付前死亡不失败；目标进度保留（击杀计数不因死亡清零）。

---

## 4. 侵蚀（局内节奏压力）

入坑后随**探索时间**累积**畸变 / 侵蚀度**（HUD 常显）。

| 畸变档 | 效果（草案，进数据表） |
|--------|------------------------|
| 低 | 小增益（如攻速微增）——诱使多待一会 |
| 中 | 幻觉干扰（假掉落提示 / 地图噪点） |
| 高 | 随机锁定 1 个已装配技能槽，或承重惩罚 |
| 极高 | 持续掉血或强制高威胁刷怪——强烈催促回城 |

- 回城 / 死亡后侵蚀清零（或按表残留，默认清零）。
- **设计意图**：打破「无脑挂机刷到包满」，与承重共同构成回城决策。

---

## 5. 区域与秘境

- 巨坑**大地图按区域划分**。第 1 层可用现名：
  - **沉苔沼**（潮腐：泥沼移速↓，雾中警戒↓）
  - **折铜谷**（磁累：金属件越多，移速 / 技能 CD 越差）
  - **盲灯廊**（回声：大声技能吸引增援）
- 每层由 **1～3** 个独立生态构成（见 `05`）。
- 区域内有**普通区域**与**隐藏秘境**：
  - 开启方式：**解密**（机关 / 谜题 / 物品组合）或**额定条件**（如击杀本区精英、侵蚀低于某档、持有指定材料、亲和力契约等）。
  - 秘境为随机实例，掉落表优于同层野外；MVP **1 个**秘境入口即可。

---

## 6. 资源获取一览

| 来源 | 产出 |
|------|------|
| 击杀 | 材料、**晶核**（低爆率，品阶随怪阶）、**XP**；**不掉金币** |
| 挖掘 / 挖矿 | 材料（可带品阶 / 品质） |
| 宝箱 | 材料、消耗品、偶发装备、偶发金币 |
| 任务交付 | **金币**、材料、XP |
| NPC 交易 | 金币买药剂等；出售材料换金 |

---

## 7. 跨日与吐息（继承，简化）

- 城镇有**日期**；休息 → 次日，念力回满。
- **吐息**（跨日事件）：每隔若干游戏日（初值每 3 日），部分区域临时封锁 + 刷新稀有精英 / 定向材料。MVP 简化版（1 类封锁 + 1 种吐息精英）；完整表后置。
- 地脉捷径：成功发现并回城后跨局解锁短路径。MVP 可后置到阶段 C/D。
