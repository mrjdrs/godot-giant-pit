## 4. 代码现状对照（v2.0 工程债务）

实现仍基本是 v2.0，**不等于** v3.0 已落地。

| 目标 | 代码 | 说明 |
|------|------|------|
| EventBus | 无 | 节点 signal + `MetaProgress.changed` |
| 数据表 | GDScript `const` | `crystal_catalog` / `region_catalog` / `loc.gd` 等 |
| 晶核掉落 | **未接线** | `pit_enemy` 注释写明击杀不掉晶核 |
| 烙印职业 | 无 | `brand_quality` = iron/copper/silver/gold；`weapon_family = "blade"` |
| 属性点 | 无 | 探索等级自动 + 体力 / 力量 |
| 品阶×品质 | 无 | `ItemTier` 五档；装备仅胸甲 + 挂坠强化整数 |
| 秘境 / 钓鱼 / NPC | 无 | 宝箱提示多为 loc 桩 |
| 四阶怪 | 部分 | 小怪 / 精英 / 看守 / BOSS 靠 ID 前缀，无 `special` 枚举 |
| 念力作 MP | 否 | 念力值用于传送 / 感悟 |
| 金币、侵蚀 HUD | **是** | 与 v3.0 对齐，可保留 |
| 破盾 | 仅横版 | 俯视待补 |
| 捷径 / 吐息 | 仅横版路径 | 俯视未接 |
| `rune_catalog.gd` | 残留 | 迁晶核后删除 |
