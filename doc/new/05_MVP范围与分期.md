# 05 — MVP 范围与分期

> 文档族：doc v2.0

---

## 1. MVP 必做

| 模块 | 内容 |
|------|------|
| 战斗 | 俯视 WASD + 左键朝鼠标普攻 + 右键/QERFC 指向技能（无跳跃/闪避） |
| 关卡 | 第 1 层三生态大地图 + 迷雾 + 3 条生态法则 |
| 生存 | 深渊侵蚀条 + 撤离/死亡结算 |
| 门禁 | 层 BOSS + 特殊念力 + 下层灰态接口 |
| 传送 | 每区锚点、看守解锁、耗念力、跨局记住 |
| 捷径 | 1 条可解锁地脉捷径 |
| 日循 | 休息回念力；1 种贵药剂 |
| 晶核 | 技能核 + 属性核；仅营地感悟 |
| XP | 击杀给经验；探索等级跨局保留 |
| 养成 | 武器觉醒 2 分支；基建绞盘机 + 探照灯 + 感悟台 |
| 背包 | 10 格 + 承重；金币分栏/纸券；杀怪不掉金 |
| 装备 | 胸甲、挂坠 + 死亡磨损 |
| 委托 | 采集/击杀/标记救援 |
| 吐息 | 简化版（封锁 1 类标记 + 1 种吐息精英） |

- 第 2 层及以下实装
- 完整吐息事件表、多捷径网
- 地底住民交易/宣战
- 奇观古龙等一次性超模事件
- 弓/杖等其它烙印操作
- AI 队友、联机、多城镇剧情
- 8 向完整动画套（MVP 用俯视占位图翻转）
- 装备修复、杀怪掉金币、坑内学技能

## 3. 制作分期

### 阶段 A — 俯视刀手感

- WASD、朝鼠标普攻、右键/Q 指向技、木桩怪、顿帧/音效  
- **验收：走位 + 指向释放是否好玩**

### 阶段 B — 单区闭环

- 大地图生成 + 迷雾 + 1 条生态法则 + 侵蚀条 + 材料/XP/晶核掉落 + 撤离结算

### 阶段 C — MVP 闭环

- 三区段 + 精英/BOSS/传送/1 捷径 + 日休念力 + 感悟台装配 + 觉醒 2 支 + 基建 2 项 + 简化吐息 + 委托 + 营地

### 阶段 D — 扩展

- 吐息全表、更多捷径、叙事/住民/奇观、第 2 层、其它烙印

## 5. 风险

| 风险 | 对策 |
|------|------|
| 俯视手感不成 | 阶段 A 死磕走位与指向释放 |
| 三法则不够鲜明 | 每条法则必须改操作或资源权衡，禁止只换怪皮 |
| 侵蚀过强劝退 / 过弱无效 | 分档可调；低档给甜头 |
| 系统过多 | 严格按本节 MVP 表；叙事奇观进 D |
| 与根目录旧文档混淆 | 以 doc/new v2.0 为准；旧文件只归档于 doc/old |
