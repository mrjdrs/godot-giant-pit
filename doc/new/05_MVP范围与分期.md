# 05 — MVP 范围与分期

> 文档族：doc v1.0

---

## 1. MVP 必做

| 模块 | 内容 |
|------|------|
| 战斗 | 横版移动/跳跃 + 大刀普攻/杀招/闪避 |
| 关卡 | 第 1 层三生态区段 + 3 条生态法则 + 段落生成 |
| 生存 | 深渊侵蚀条 + 撤离/死亡结算 |
| 门禁 | 层 BOSS + 特殊念力 + 下层灰态接口 |
| 传送 | 每区锚点、非边缘、看守解锁、耗念力、跨局记住 |
| 捷径 | 1 条可解锁地脉捷径 |
| 日循 | 每日入坑 1 次；休息回念力；1 种贵药剂 |
| 符文 | 技能型 4 + 属性型 4；坑内/外耗念力学 |
| 养成 | 武器觉醒 2 分支；基建绞盘机 + 探照灯 |
| 背包 | 10 格 + 承重；金币分栏/纸券；杀怪不掉金 |
| 装备 | 胸甲、挂坠 + 死亡磨损 |
| 委托 | 采集/击杀/标记救援 |
| 吐息 | 简化版（封锁 1 类节点 + 1 种吐息精英） |

## 3. 制作分期

### 阶段 A — 横版刀手感

- 移动、跳跃、普攻、杀招、闪避、木桩怪、顿帧/音效  
- **验收：刀是否好玩**

### 阶段 B — 单区段环

- 单一生态区段生成 + 1 条生态法则 + 侵蚀条 + 背包拾取 + 撤离结算

### 阶段 C — MVP 闭环

- 三区段 + 精英/BOSS/传送/1 捷径 + 日休念力 + 符文学习 + 觉醒 2 支 + 基建 2 项 + 简化吐息 + 委托 + 营地

### 阶段 D — 扩展

- 吐息全表、更多捷径、叙事/住民/奇观、第 2 层、其它烙印

## 5. 风险

| 风险 | 对策 |
|------|------|
| 横版手感不成 | 阶段 A 死磕 |
| 三法则不够鲜明 | 每条法则必须改操作或资源权衡，禁止只换怪皮 |
| 侵蚀过强劝退 / 过弱无效 | 分档可调；低档给甜头 |
| 系统过多 | 严格按本节 MVP 表；叙事奇观进 D |
| 与根目录旧文档混淆 | 以 doc/new 为准；旧文件只归档于 doc/old |
