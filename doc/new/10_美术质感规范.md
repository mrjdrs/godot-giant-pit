# 10 — 美术质感规范

> 文档族：doc v3.0｜坑内俯视 + 城镇俯视  
> 生成脚本：`giant-pit/tools/gen_mvp_pixel_art.py`（legacy 俯视 / UI）  
> 场景氛围：`giant-pit/scripts/fx/scene_atmosphere.gd`

---

## 风格锚点

| 项 | 定案 |
|----|------|
| 大类 | **炼金奇幻卡通像素**（非写实、非纯扁平色块） |
| 轮廓 | `#2A1F18` |
| 炼金青 | `#3D8B7A` |
| 烙印金 | `#E8A838` |
| 鹰眼木褐 | `#8B5A2B`（弓身、弩机、矛杆） |
| 元素晶 | 冰 `#7EC8E8` / 火 `#E85A3A` / 酸 `#A8D44A` / 暗 `#5A4A78` / 光 `#F4E6A8` |
| 亲和紫 | `#8B6BB8`（契约纹、召唤物描边） |
| 视角 | 坑内 / 战斗：**俯视 2D**；城镇 Hub：**俯视 2D** |

目标观感：像素清晰、块面有体积、三区色调可辨，而非「程序矩形占位图」。局内角色用 **四向扁模型**（下/右/上/左），不做 8 视图。

鹰眼武器为木弓 / 弩机 / 矛，禁止现代枪械剪影。**禁止独立武器精灵**：武器画进四向角色表，按 `held_weapon` 换整张模型。

## 像素与渲染规范

| 规则 | 说明 |
|------|------|
| 前景过滤 | 地面 / 敌人 / 道具 tile：**Nearest**；烙印四向表：**Linear**（HD-2D） |
| 相机 zoom | 玩家 Camera2D **2.5**（整数倍感；勿随意改 collision 尺度） |
| 光源方向 | **固定左上**；所有程序化 shading 统一 |
| 体积 shading | 每个部位 ≥ **基色 / 高光 / 阴影 / 轮廓** 四档 |
| 角色尺寸 | 四向帧 **64×88**，局内约 **0.48×0.85**（约 1 格宽、略高于 1 格）；脚点对齐碰撞；tile **32×32** |
| 地面铺设 | **32px tile** 重复 |

## 三区调色（CanvasModulate）

| 生态 | preset | 倾向 | 雾尘粒子 |
|------|--------|------|----------|
| 沉苔沼 moss | `(0.88, 0.96, 0.90)` | 偏绿、潮湿 | 孢子、苔屑 |
| 折铜谷 copper | `(0.98, 0.90, 0.82)` | 偏暖、矿锈 | 铜屑、尘粒 |
| 盲灯廊 / 回声 echo | `(0.82, 0.86, 1.0)` | 偏紫、冷 | 漂浮光点 |
| Hub 城镇 hub | `(1.0, 0.96, 0.88)` | 暖石、炉火感 | 少而弱 |
| 秘境（草案） | 比本区更饱和 / 更暗 | 与母区同色相、对比更高 | 表定 |

进入生态时更新 `SceneAtmosphere.set_biome()`。迷雾用 chunk 遮罩，禁止纯 ColorRect 当主视觉（可用半透明 tile）。

## 烙印占位规范（阶段 D 美术）

| 烙印 | MVP | 占位要求 |
|------|-----|----------|
| 战痕 · 刀 | 主路径 | 四向表内嵌刀；无独立 `BladeSprite`；无黑边方底 |
| 鹰眼 · 弓 | 可选 | 四向表内嵌弓；弹道为箭矢，弦振闪光忌枪口白片 |
| 元素 | 可选 | 凝聚元素姿态；弹道用对应元素色；无独立杖网格 |
| 亲和 | 可选 | 契约姿态；召唤物轮廓色 = 亲和紫 + 生物本色 |

品质色边框与 `04` 六档品质对齐（普通灰 → 神话红焰）。品阶可用角标「九」～「一」，勿用品质色重复表达品阶。

---

## 场景层次（由远到近）

1. **CanvasModulate** — 全区色调  
2. **地面 / 墙** — tile 重复  
3. **迷雾 chunk**  
4. **实体** — 玩家、敌人、交互物、掉落  
5. **轻暗角** — `vignette.gdshader`，强度默认 **0.22**

Hub：暖色 modulate + 砖缝 floor + 像素墙 tile。

---

## 禁止项

- 小图暴力 `scale` 当全屏背景
- 纯 `ColorRect` 作为雾 / 泥 / 背景主视觉
- 无明暗的单色块角色 / 敌人
- 前景使用 Linear 过滤
- 现代枪械剪影、独立武器精灵叠在空手身体上、霓虹赛博 HUD（与炼金奇幻冲突）
