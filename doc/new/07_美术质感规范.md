# 07 — 美术质感规范

> 文档族：doc v1.0｜侧视坑内 + 俯视 Hub 营地  
> 生成脚本：`giant-pit/tools/gen_sideview_art.py`  
> 场景氛围：`giant-pit/scripts/fx/scene_atmosphere.gd`

---

## 风格锚点

| 项 | 定案 |
|----|------|
| 大类 | **炼金奇幻卡通像素**（非写实、非纯扁平色块） |
| 轮廓 | `#2A1F18` |
| 炼金青 | `#3D8B7A` |
| 烙印金 | `#E8A838` |
| 视角 | 坑内/战斗：**侧视 2D**；Hub：**俯视 2D**（操作不变） |

目标观感：像素清晰、块面有体积、场景有纵深与区辨色调，而非「程序矩形占位图」。

---

## 像素与渲染规范

| 规则 | 说明 |
|------|------|
| 前景过滤 | 角色、敌人、道具、地面 tile：**Nearest** |
| 相机 zoom | 玩家 Camera2D **2.5**（整数倍感；勿随意改 collision 尺度） |
| 光源方向 | **固定左上**；所有程序化 shading 统一 |
| 体积 shading | 每个部位 ≥ **基色 / 高光 / 阴影 / 轮廓** 四档 |
| 角色尺寸 | **32×48**（侧视 pose）；tile **32×32** |
| 视差背景 | **160×96** 大画布 `bg_far.png` / `bg_mid.png`，整数倍放大；**禁止** 32×32 小图 `scale` 20+ 倍铺满 |
| 地面铺设 | 横向 **repeat 32px tile**；平台用 `platform.png`，不用 ground 拉伸 |

---

## 三区调色（CanvasModulate）

| 生态 | preset | 倾向 | 雾尘粒子 |
|------|--------|------|----------|
| 沉苔沼 moss | `(0.88, 0.96, 0.90)` | 偏绿、潮湿 | 孢子、苔屑 |
| 折铜谷 copper | `(0.98, 0.90, 0.82)` | 偏暖、矿锈 | 铜屑、尘粒 |
| 回声廊 echo | `(0.82, 0.86, 1.0)` | 偏紫、冷 | 漂浮光点 |
| Hub 营地 hub | `(1.0, 0.96, 0.88)` | 暖石、炉火感 | 少而弱 |

段切换或进入生态时更新 `SceneAtmosphere.set_biome()`。

---

## 场景层次（由远到近）

1. **视差远层** `bg_far.png` — scroll_scale ≈ `(0.12, 0)`
2. **视差中层** `bg_mid.png` — scroll_scale ≈ `(0.35, 0)`
3. **CanvasModulate** — 全区色调
4. **地面 / 平台 / 墙** — tile 重复 + 变体
5. **实体** — 玩家、敌人、交互物
6. **前景雾/泥** — `fog.png` / `mud.png` 半透明 Sprite（非纯 ColorRect）
7. **轻暗角** — `vignette.gdshader`，强度默认 **0.22**（勿过重）

Hub 俯视：暖色 modulate + 砖缝 floor + 像素墙 tile；坑口/绞盘/探照可加极弱 `PointLight2D` 作色晕。

---

## 禁止项

- 小图暴力 `scale` 当全屏背景
- 纯 `ColorRect` 作为雾/泥/背景主视觉
- 无明暗的单色块角色/敌人
- 前景使用 Linear 过滤（背景远层可保持 Nearest + 大图）

## 验收清单

### 坑内 `side_pit_floor.tscn`

- [ ] 背景有视差纵深，无巨型竖条纹拉伸
- [ ] 三区进入时色调可辨（moss / copper / echo）
- [ ] 地面/平台为 tile 重复，顶边有高光
- [ ] 沉苔泥/雾使用贴图而非纯色块
- [ ] 侵蚀 HUD 显示 `ui/side/erosion.png` 图标

### 战斗原型 `combat_arena_side.tscn`

- [ ] 与坑内 moss 段同一套氛围（视差 + 调色 + 暗角）
- [ ] 地面/平台/墙铺设方式与坑内一致
- [ ] 木桩与连斩手感无回归

### Hub `crane_hub.tscn`

- [ ] 地板砖有砖缝与明暗，墙为像素 tile
- [ ] 暖色营地调色 + 轻暗角
- [ ] 坑口/基建设施剪影有体积阴影
- [ ] 俯视移动与交互无回归
