# 《巨坑之下》设计文档（现行）

> **本目录为现行设计源。**  
> [`doc/old/`](../old/) 下的 `策划案_MVP.md`、`游戏设定构思.txt`、`《巨坑之下》游戏核心玩法调整.md` 等为**归档参考**，冲突时以 **doc/new/** 为准。

## 品类定案

- **横版（侧视）2D 动作** + **肉鸽**：每局程序生成侧视房间/段落；死亡重开；养成偏局外。
- 核心循环强调**水平宽度**（路线/生态/侵蚀/基建/武器质变），而非纯数值刷子。
