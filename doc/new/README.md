# 《巨坑之下》设计文档（现行）

> **本目录为现行设计源：doc v3.0。**  
> [`doc/old/v2.0/`](../old/v2.0/) 为 2026-08-10 俯视肉鸽条文的冻结副本；[`doc/old/`](../old/) 下其余文件为更早归档。冲突时以本目录为准。

## 品类定案

- **俯视 2D 探索 ARPG** + **城镇养成**：创角选择**烙印天赋**（永久职业方向）；巨坑大地图按区域探索；死亡回城/锚点，不重开角色。
- 手感对标火炬之光 2 的走位与指向释放，**不做** 3D 等距。
- 核心循环：**战斗 → 获取（材料 / 晶核 / XP）→ 成长 → 再战斗**；侵蚀逼迫节奏，秘境提供横向高风险内容。
