# 06 — 界面与交互系统

> 文档族：doc v3.0

---

## 1. UI 清单

| 界面 | 职责 | 热键 / 入口 |
|------|------|-------------|
| **主菜单** | 新游戏 / 读档 / 设置 / 退出；新游戏时选烙印 | 启动 |
| **HUD** | 战斗中常驻信息 | 入坑 / 城镇 |
| **角色面板** | 属性、未分配点数、装备总览 | **V** |
| **背包** | 格、承重、使用消耗品 | **Tab / B** |
| **技能树** | 学习 / 升级 / 装配热键 | **K** |
| **任务追踪** | 当前任务目标与进度 | HUD 侧栏；城镇告示板 |
| **地图** | 大地图（区域 / 迷雾 / 锚点 / 秘境）+ 小地图 | **M** + HUD 角 |
| **对话** | NPC | 空格 |
| **死亡 / 回城确认** | 复活点提示、磨损结算 | 事件弹出 |

---

## 2. HUD（必显）

| 元件 | 说明 |
|------|------|
| **快捷栏** | 左键普攻 + 右键 / Q / E / R / F / C；显示图标、CD、锁定（侵蚀） |
| **生命** | 当前 / 上限；受击闪红 |
| **念力** | 当前 / 上限；放技能扣减，不足时槽位变暗 |
| **侵蚀度** | 条或球；分档变色（低 / 中 / 高 / 极高） |
| 区段名 | 当前生态名 |
| XP | 等级 + 经验条（可较小） |
| 状态图标 | 泥沼 / 雾隐 / 磁累 / 技能锁定 / 超重等 |
| 交互提示 | 靠近可互动物时 |

现有 [`skill_bar.gd`](../../giant-pit/scripts/ui/skill_bar.gd) 已有 HP 球、六槽、侵蚀球、XP、状态图标；v3.0 需把侵蚀旁的资源语义改为**战斗念力**，并显示消耗预览。

---

## 3. 角色面板

- 烙印系 + 武器类型
- 六主属性 + 加减点（有未分配点时）
- 衍生攻防、暴击、承重、念力上限 / 回复、侵蚀抗性
- 装备槽缩略（点开可对比）
- MVP：力量 / 体力可点；其余属性可显示但灰态或同样可点（推荐六维都可点，避免返工）

---

## 4. 背包

- 网格 + 承重条 + 金币（分栏）
- 悬停：名称、品阶、品质色、描述、重量
- 晶核与材料用品质色边框
- 使用消耗品；不可把任务物卖出

---

## 5. 技能树

- 按烙印分系分页（MVP 仅刀系一页）
- 节点：未学 / 可学 / 已学 / 品阶不足
- 学习确认：消耗晶核预览
- 已学主动技可拖到热键；被动列表单独一栏

---

## 6. 任务追踪与地图

- 追踪：当前任务名、计数（击杀 N / 采集 N / 送达）、区域提示
- 小地图：已探索 chunk、玩家、锚点、任务标记（迷雾外不显示未探索点）
- 大地图：区域色、领主域、秘境入口（已发现）、迷雾

---

## 7. 主菜单与存档

- 单机本地存档（沿用 `user://meta_save.json` 方向，字段随 v3.0 扩展：烙印、属性点、品阶装备等）
- 设置：音量、键位（后置可改键）

---

## 8. 输入总表（与 `03` 一致）

移动 WASD；左键普攻；右键技能 1；QERFC 技能 2～6；空格交互；滚轮切掉落；Tab/B 背包；V 角色；K 技能树；M 地图。
