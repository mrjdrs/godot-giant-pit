# 08 — MVP 范围与分期

> 文档族：doc v3.0

---

## 1. MVP 必做

| 模块 | 内容 |
|------|------|
| 战斗 | 俯视 WASD + 左键朝鼠标普攻 + 右键 / QERFC 指向技能（无跳跃 / 闪避）；**技能耗念力**；HUD 生命 / 念力 |
| 烙印 | 创角固定 **冷兵器 · 刀**（可跳过选系 UI，写死刀系） |
| 成长 | 击杀 + 任务给 XP；升级给 **属性点**（至少力量 / 体力可分配） |
| 关卡 | 第 1 层大地图：**1～2 生态先跑通**，目标三区（沉苔沼 / 折铜谷 / 盲灯廊）+ 迷雾 + 生态法则 |
| 生物 | 小怪 + 精英 + **1 名领主**；特殊怪可 1 个占位或后置 |
| 掉落 | 材料、XP、**晶核（必须接线）**；杀怪不掉金 |
| 挖矿 | 至少 1 类矿 / 采集点 |
| 生存 | 侵蚀条 + 死亡回城 / 锚点（装备磨损）；**不再**自选 1 格 |
| 秘境 | **1 个**入口（解密或条件）；实例可极简 |
| 城镇 | 静态 Hub：休息回念力、感悟台 / 技能树学习、商店药剂、出售换金、任务告示 |
| 装备 | 武器 + 胸甲 + 挂坠；品阶×品质 **最小集**（可先只做品质 3 档 + 品阶 2 档，枚举按 v3.0 留好） |
| 经济 | 仅金币；任务交付 + 出售 |
| 传送 | 每区锚点、看守解锁、耗念力、跨局记住 |
| 下层 | 灰态接口 |

## 2. 明确不做（后置）

- 热武器 / 法杖元素 / 亲和力召唤的完整操作
- 斧、剑、锤、矛、弓（刀除外）
- 点击移动、3D 等距、随机词缀装备雨
- 第 2 层及以下实装
- 完整吐息事件表、多捷径网
- 钓鱼、坑内 NPC 网、多城镇剧情
- AI 队友、联机
- 8 向完整动画套（MVP 用俯视占位图翻转）
- 杀怪掉金币、独立念力等级养成
- EventBus **全量**替换旧 signal（新代码优先总线即可）
- 纸券减重

---

## 3. 制作分期

### 阶段 A — 俯视刀手感 + 念力

- WASD、朝鼠标普攻、右键 / Q 指向技、木桩怪、顿帧 / 音效
- **放技能扣念力**；HUD 显示生命 + 念力
- **验收：走位 + 指向释放 + 念力是否好玩**

### 阶段 B — 单区闭环

- 大地图生成 + 迷雾 + 1 条生态法则
- 侵蚀条 + 材料 / XP / **晶核掉落接线** + 挖矿
- 属性点（升级可点）
- 死亡回城或锚点 + 磨损
- 俯视 **破盾**（精英先做）

### 阶段 C — MVP 闭环

- 2～3 区段 + 精英 / 领主 / 传送 + 1 秘境
- 城镇静态：休息、技能树学习、金币经济、委托
- 装备槽最小集（品阶×品质）
- 侵蚀 HUD 分档效果
- 简化吐息（可选）

### 阶段 D — 扩展

- 热武器 / 法杖 / 召唤烙印
- 下层、特殊怪完整表、钓鱼、更多秘境
- EventBus 全量迁移 + JSON 数据表替换 GDScript const
- 吐息全表、捷径网、叙事

## 4. 工程债务（不挡文档，阶段 B 必须碰）

| 项 | 现状 | MVP 要求 |
|----|------|----------|
| 晶核掉落 | `pit_enemy` 只掉材料 + XP，掉核函数未调用 | **B 必须接线** |
| 破盾 | 仅横版 `side_enemy` | 俯视精英 / 领主要有 |
| 捷径 / 吐息 | 仅横版路径 | C/D 再接到俯视 |
| 每日入坑限制 | 代码已关闭 | 保持关闭（v3.0 不限每日 1 次） |
| `rune_catalog` | 与晶核并存 | 迁完删除 |
| `ItemTier` | 5 档、无品阶 | C 扩为 6 品质 + 9 品阶枚举 |
| EventBus / JSON 表 | 无 | 新系统按 `07` 做；全量迁 D |

---

## 5. 风险

| 风险 | 对策 |
|------|------|
| 俯视手感不成 | 阶段 A 死磕走位与指向释放 |
| 四系烙印范围爆炸 | MVP 只做刀；其它系只写表不实装 |
| 品阶×品质组合过多 | MVP 最小枚举 + 少词缀 |
| 侵蚀过强劝退 / 过弱无效 | 分档可调；低档给甜头 |
| 与根目录旧文档混淆 | 以 `doc/new` v3.0 为准；v2.0 只在 `doc/old/v2.0/` |
