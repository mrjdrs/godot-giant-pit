## 1. 横版基础操作

| 输入 | 行为 |
|------|------|
| 移动 | 左右（及必要的爬梯/绳，后置） |
| 跳跃 | **基础移动**（横版必备；不占用技能槽键位） |
| 普攻 | 鼠标左键 |
| 杀招 | 鼠标右键 |
| 绝技 | Q（MVP 可后置） |
| 防御技 | Ctrl（MVP 可后置） |
| 闪避技 | 空格 |
| 被动 | 无键，常驻 |

手感验收（P0）：

1. 挥空有重量感（动画 + 顿帧 + 音效）。  
2. 跳跃与斩击有衔接窗口；空中贪刀可罚。  
3. 贴脸受明确反击窗惩罚。

## 2. 烙印 = 武器栏

- 每局生成 **1** 个主烙印，装备在**武器栏**。
- 烙印**类型**限制可学/可装备技能池（大刀 → 仅刀类）。
- MVP：**仅大刀类型**；品质受念力等级权重影响。
- 烙印为**局内存在**：撤离/死亡后消散；**已学技能跨局保留**。

### 品质分档

| 品质 | 名称例 | 表现 |
|------|--------|------|
| 普通 | 铁纹 | 基础物攻 |
| 精良 | 铜纹 | 小幅物攻/判定 |
| 稀有 | 银纹 | 轻微特效 |
| 史诗 | 金纹 | 明显特效 |

### 念力等级 → 品质权重（初表）

| 等级 | 普通 | 精良 | 稀有 | 史诗 |
|------|------|------|------|------|
| 1 | 70% | 25% | 5% | 0% |
| 2 | 55% | 35% | 9% | 1% |
| 3 | 40% | 40% | 16% | 4% |
| 4 | 28% | 42% | 22% | 8% |
| 5 | 18% | 40% | 30% | 12% |

## 3. 武器觉醒分支（质变 · MVP 大刀 2 支）

局外用**定向材料**对大刀系进行觉醒（改变技能逻辑，而非只加数字）：

| 分支 | 名称 | 质变方向 | 定向材料来源（草案） |
|------|------|----------|----------------------|
| 甲 | 旋风锋 | 普攻/杀招偏 AOE 清怪，更适合沉苔沼群怪 | 沉苔沼精英 / 沼心虫残壳 |
| 乙 | 铁壁反 | 防御/杀招偏格挡反击，更适合折铜谷硬敌 | 折铜谷精英 / 甲壳残片 |

- 同时只能激活一条觉醒主分支（可消耗材料切换，成本高）。
- 未觉醒时使用基础大刀普攻/杀招/闪避。
- **设计意图**：养成改变操作，并倒逼「去特定危险区段刷定向材料」。

## 4. 符文

### 类型

| 类型 | 作用 |
|------|------|
| 技能型 | 解锁/升级某技能（须烙印类型匹配） |
| 属性型 | 少量属性；暴击/爆伤可补但**严控幅度** |

### 学习

- 符文进背包，**不自动生效**。
- **坑内或坑外**打开学习面板，消耗**念力值**学习。
- 高品质另需**念力等级**门槛。
- 学成后技能入池或属性永久增加；符文道具消耗。

### 掉落

- 整体爆率低。
- 高品质**不上**低级杂兵表；仅精英/BOSS/吐息/高威胁段。

| ID | 类型 | 名称 | 效果草案 | 门槛 |

| S2 | 技能 | 崩山击 | 强化杀招 | 1 |

## 6. 敌人韧性（破盾）

侧视敌人除生命外拥有 **韧性条**。玩家命中时同时扣除 HP 与韧性：

| 状态 | 表现 |
|------|------|
| 未破防 | 短硬直（约 0.12s）；伤害 ×1 |
| 破防 | 韧性归零 → 眩晕约 1.2s；期间受伤 ×1.5；眩晕结束韧性回满 |

轻斩三段 / 杀招对韧性伤害不同（见 [`hitbox.gd`](../giant-pit/scripts/combat/hitbox.gd) `poise_damage`）。破防窗口鼓励连段贪刀。

## 7. 侧视敌人原型（全局共用）

| ID | 名称 | 类型 | 攻击方式 |
|----|------|------|----------|
| `side_melee` | 苔刺甲虫 | 近战 | 前摇 → 短距冲刺斩 |
| `side_ranged` | 孢囊射手 | 远程 | 保持距离，抛物线孢弹 |
| `side_flyer` | 沼灯游蝇 | 飞行 | 悬停俯冲或水平弹 |
| `side_elite` | 沼域领卫 | 精英 | 蓄力冲撞 + 近身重砸 |
| `side_boss` | 坑冠兽 | BOSS | 砸地冲击波 / 连发弹幕 / 跃砸 |

- 战斗段混刷三种普通怪；精英段刷 `side_elite`；层 BOSS 刷 `side_boss`。
- 普通怪与精英头顶显示 HP + 韧性条；BOSS 血条在屏幕顶栏。
