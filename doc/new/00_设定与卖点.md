# 00 — 设定与卖点

> 文档族：doc v1.0｜游戏名：**巨坑之下**

---

## 一句话卖点

在鹤城裂开的巨坑中，以**横版烙印战斗**深入随机生成的生态区段：应对**区域法则**与**深渊侵蚀**，带出定向材料；回营地做**基建**与**武器觉醒分支**，再迎下一场吐息与捷径——越深越肥，也越难全身而退。

---

## 体验支柱

| 优先级 | 支柱 | 玩家应感到 |
|--------|------|------------|
| P0 | **横版烙印手感** | 大刀有重量、跳跃与斩击有节奏、贪刀受罚 |
| P1 | **生态 + 侵蚀生存** | 每区玩法不同；待太久会畸变，必须规划返航 |
| P2 | **基建 + 武器质变** | 带回物改变下一局探索方式，而不只是攻击 +5 |
| P3 | **委托 / 叙事钩子** | 有明确事做；深层有故事（MVP 轻量，完整后置） |

## 世界观骨架

某日，龙国中部**鹤城**突发异震，市心裂开一座**巨坑**。

坑中出现人间未见的生物与矿脉。唯有具备足够**精神念力**者可被坑口接纳。朝廷**探坑司**与地方**炼金公会**招募适格者下潜，带回材料与情报。

**你的故事，从第一次被烙印选中、踏入横贯坑壁的探路开始。**

城镇可见：炼金台、机关门、鉴定灯、补给车、兑换所、旅店、**营地基建**（绞盘、探照等）。

---

## 设计原则（反单调）

1. **空间有横向选择**：生态法则不同 → 路线与装备策略不同。  
2. **生存有不可逆压力**：侵蚀条逼迫撤离时机，而非刷到包满。  
3. **养成要质变操作**：武器觉醒改技能逻辑；基建改下一局探索效率。  
4. **世界会对你有反应**：吐息、捷径解锁，让「下次下潜」有事件目标。
