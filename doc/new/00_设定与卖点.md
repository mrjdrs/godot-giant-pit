# 00 — 设定与卖点

> 文档族：doc v3.0｜游戏名：**巨坑之下**

---

## 一句话卖点

在鹤城裂开的巨坑中，以**俯视烙印战斗**探索按区域划分的大地图：选定**烙印天赋**决定武器与技能树，用战斗与挖矿换**材料 / 晶核 / 经验**，强化后再挑战更深层级与隐藏**秘境**——侵蚀催促节奏，越深越肥，也越难从容。

---

## 体验支柱

| 优先级 | 支柱 | 玩家应感到 |
|--------|------|------------|
| P0 | **火炬式走位与指向技能** | WASD 走位、鼠标瞄准释放干净；技能有冷却、落点与**念力消耗** |
| P1 | **烙印职业方向** | 创角选定战痕 / 鹰眼 / 元素 / 亲和，后续武器池与技能树被锁死方向 |
| P2 | **晶核技能树 + 属性点** | 高阶怪掉高品阶晶核（低爆率）；升级自己加点；成长可感知 |
| P3 | **生态 + 侵蚀 + 秘境** | 每区玩法不同；待太久会畸变；解密或条件可开隐藏秘境 |

## 世界观骨架

某日，龙国中部**鹤城**突发异震，市心裂开一座**巨坑**。

坑中出现人间未见的生物与矿脉。唯有具备足够**精神念力**者可被坑口接纳。朝廷**探坑司**与地方**炼金公会**招募适格者下潜，带回材料、晶核与情报。

适格者被一种**烙印天赋**选中：有人承战痕近战，有人开鹰眼远射，有人凝自然元素，有人与动物或植物缔约。烙印一旦选定，便决定此人在坑中的战斗方式。

**你的故事，从第一次被烙印选中、踏入迷雾覆盖的坑层开始。**

城镇可见：炼金台、机关门、鉴定灯、补给车、兑换所、旅店、**感悟台（技能树）**、营寨设施、渔点（后置）。

---

## 设计原则

1. **职业有横向选择**：四系烙印操作手感不同，不是换皮数值。  
2. **空间有横向选择**：生态法则不同 → 路线与装备策略不同；秘境是区内高风险支线。  
3. **生存有节奏压力**：侵蚀条催促不要无限挂机刷，而非强制「一局清包重开」。  
4. **养成要可调**：属性点自选；晶核品阶门槛让高阶技能值得去打高阶怪。  
5. **模块可拆**：系统按七大维度划分，用事件总线通信，数值进数据表。

## 与 v2.0 卖点差异（摘要）

| v2.0 | v3.0 |
|------|------|
| 每局随机烙印，撤离消散 | 创角选烙印，永久 |
| 无枪械 | 玩家职业为战痕 / 鹰眼 / 元素 / 亲和（无枪炮职业） |
| 念力只用于传送 / 感悟 | 念力 = 放技能消耗（传送亦可耗） |
| 一局撤离 / 死亡自选 1 格 | 死亡回城或锚点；装备磨损 / 侵蚀惩罚 |
| 反「纯数值刷子」为主叙事 | 承认成长循环，用侵蚀 + 秘境 + 职业手感防单调 |
