# 05 — 世界与关卡系统

> 文档族：doc v3.0

---

## 1. 场景系统

游戏世界由两类场景构成：

| 类型 | 例子 | 生成 |
|------|------|------|
| **静态** | 鹤城镇、固定地牢（剧情 / 教学 / 常驻领主巢） | 手摆或固定 tile |
| **随机** | 巨坑野外大地图、副本、**秘境**实例 | 程序生成（种子可存档） |

### 1.1 鹤城镇（静态 Hub）

设施（可渐进实装）：告示板（任务）、炼金台（打造 / 修理）、感悟台（技能树）、旅店（休息）、兑换所 / 商店、仓库、坑口、（后置）渔点。

城镇可俯视移动 + 空格交互（沿用现 `crane_hub.tscn` 方向）。

### 1.2 巨坑野外大地图（随机）

- 按**区域 / 生态**划分；战争迷雾：未探索 chunk 遮盖，走近揭示并记住。
- 进入新区：横幅显示区段名；HUD 常显当前区段。
- 内容点：战斗、采集、挖矿、事件、精英、特殊怪、领主域、传送锚点、秘境入口、撤离 / 回城点、任务目标、宝箱、机关。

### 1.3 固定地牢（静态）

- 用于教学、主线节点、常驻领主。
- MVP 可不做独立地牢，用第 1 层领主域代替。

### 1.4 副本 / 秘境（随机实例）

- 从大地图入口进入，单独场景。
- 秘境开启：解密或额定条件（见 `01`）。
- 失败惩罚：轻量（死亡按主世界规则回城；实例内进度不保存）。MVP 不做额外「副本清空包」。

## 2. 关卡系统（巨坑层级）

- 越深 **难度越高**，掉落品阶上限越高。
- 每层由 **1～3** 个**独立生态**构成。
- MVP：第 1 层，**1～2 个生态**先跑通，目标仍是三区（沉苔沼 / 折铜谷 / 盲灯廊）；第 2 层+ 灰态入口。

### 2.1 第 1 层生态（可沿用 v2.0 法则）

| 区段 | 名称 | 生态法则 |
|------|------|----------|
| A | 沉苔沼 | **潮腐**：泥沼地形移速↓；雾中隐身时敌人警戒↓ |
| B | 折铜谷 | **磁累**：金属件越多，移速 / 技能冷却越差 |
| C | 盲灯廊 | **回声**：范围 / 砸地等「大声」技能短暂吸引增援 |

法则必须改操作或资源权衡，禁止只换怪皮。

### 2.2 传送锚点

- 每生态区段随机 **1** 个锚点（避免刷在区段首尾边缘）。
- 绑定看守（精英级或特殊守卫）；击杀后激活。
- **跨局永久记住**已激活锚点。
- 消耗念力：入坑传到已解锁锚点；局内已激活锚点互传（数值见 `03`）。

### 2.3 下层接口

- 第 1 层领主域：击杀领主可获「下层通行证」类物品或标记。
- MVP 下层未实装 → 灰态 / 「更深之径未开」。

## 3. 四阶生物

| 等级 | 定位 | 掉落倾向 |
|------|------|----------|
| **小怪** | 数量、清场、低品阶材料 / 晶核 | 九～七品 |
| **精英** | 区段高威胁，非门禁 | 七～四品，定向材料 |
| **特殊怪** | 稀有机制（飞行、隐身、反召唤、谜题相关） | 五～三品；可掉秘境钥匙 / 契约 |
| **领主** | 层或区终局 BOSS | 四～一品；通行证 / 高阶晶核 |

- 战斗区混刷小怪；精英点刷精英；特殊怪低概率或条件刷新；领主域刷领主。
- 传送看守可归入精英或特殊怪（表定）。
- 飞行怪作为特殊怪或小怪变体（攻击方式与弹道独立，见构思历程 08-07）。

## 4. 交互系统

| 交互 | 说明 | MVP |
|------|------|-----|
| NPC 对话 | 城镇必做；坑内 NPC 后置 | 城镇阶段 C |
| 开启宝箱 | 有锁 / 无锁；陷阱箱；品阶×品质掉落 | 阶段 C |
| 触发机关 | 秘境开门、捷径、谜题压板 / 顺序灯 | 秘境 1 个即可 |
| 钓鱼 | 城镇或沼区渔点；休闲；少量材料 / 金币 | **后置（D）** |
| 采集 / 挖矿 | 资源节点，耗时或扣耐久 | 阶段 B |
| 回城 / 锚点 / 下层门 | 见上 | 阶段 B/C |

统一交互键：**空格**。可互动物显示提示条。

## 5. 迷雾与探照（继承，可选）

- 未探索 chunk 迷雾；揭示后记住。
- 城镇设施「探照灯」：提前揭示相邻 chunk；高等级轻微预警精英。MVP 可后置，不挡主循环。

---

## 6. 吐息与捷径（继承，简化）

- 吐息：跨日区域封锁 + 稀有刷新（`01`）。
- 捷径：局内发现开关，回城后永久解锁短路径。阶段 D 或 C 末再接俯视层（现行代码仅横版路径有）。
