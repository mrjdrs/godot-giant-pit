## 1. 俯视基础操作

| 输入 | 行为 |
|------|------|
| 移动 | WASD / 方向键（八向） |
| 普攻 | 鼠标左键，朝向鼠标（近战斩 / 弓矢 / 元素弹 / 藤弹，视烙印） |
| 技能 1 | 鼠标右键，释放点 = 鼠标世界坐标 |
| 技能 2～6 | **Q / E / R / F / C**，释放点 = 鼠标世界坐标 |
| 交互 | **空格**（或点击可互动物） |
| 切换堆叠掉落 | 鼠标滚轮 |
| 背包 | Tab / B |
| 属性 | **V** |
| 技能树 | **K** |
| 地图 | **M**（后置可与小地图合一） |

**取消**：跳跃、闪避 / 翻滚（防御技后置，不占热键）。

手感验收（P0）：

1. 走位流畅，攻击 / 放技能时角色朝向鼠标。  
2. 挥空 / 开火有重量感（动画 + 顿帧 + 音效）。  
3. 技能落点清晰，冷却与**念力消耗**可读。

## 2. 技能槽

| 键 | 槽 ID | 说明 |
|----|-------|------|
| 左键 | `basic` | 烙印 / 当前武器自带普攻，不可卸下 |
| 右键 | `rmb` | 可装配主动技能 |
| Q | `q` | 可装配 |
| E | `e` | 可装配 |
| R | `r` | 可装配 |
| F | `f` | 可装配 |
| C | `c` | 可装配主动或快捷被动开关（表定） |

被动技能：**不占热键**，在技能树启用后常驻（有上限，初表 4 个被动位）。

侵蚀高档可随机锁定 `rmb/q/e/r/f/c` 中 1 个已装配槽。

## 3. 技能：主动 / 被动 + 晶核

### 原则

- 技能分 **主动** 与 **被动**。
- **晶核**由怪物掉落（低爆率），进背包，计承重。
- **学习 / 升级**消耗对应晶核，且要求晶核 **品阶 ≥ 技能档要求**；品质影响成功率或溢出经验（初表：只卡品阶，品质仅卖价 / 分解）。
- 越高级的怪物（精英 / 特殊怪 / 领主）掉落晶核**品阶越好**；小怪以低品阶为主。
- 持有合格晶核即可在**技能树面板**学习（城镇或坑内均可）。感悟台提供总览、预览与（后置）重置。
- 已学技能永久保留。

### 晶核爆率（初表，进 `data/loot_tables.json`）

| 生物等级 | 技能晶核 | 属性 / 被动晶核 | 品阶权重倾向 |
|----------|----------|-----------------|--------------|
| 小怪 | 2% | 3% | 九～七品 |
| 精英 | 12% | 10% | 七～四品 |
| 特殊怪 | 18% | 12% | 五～三品 |
| 领主 | 35% | 20% | 四～一品 |

吐息精英 / 秘境内怪物：在上表基础上乘系数（初值 ×1.5），仍受幸运加成。

### 学习门槛（初表）

| 技能档 | 最低晶核品阶 | 角色等级 | 念力消耗（主动，每次释放） |
|--------|--------------|----------|----------------------------|
| 低 | 八品 | 1 | 8～15 |
| 中 | 六品 | 5 | 16～28 |
| 高 | 四品 | 10 | 30～50 |
| 绝 | 二品 | 18 | 55+ |

升技能等级：再消耗同 ID 晶核（品阶 ≥ 当前技能档）+ 递增材料（可选）。

| `core_s_chain` | 被动 | 连环斩核 | 近战小怪 |
| `core_s_quake` | 主动 | 崩山击核 | 远程小怪 |
| `core_s_dash` | 主动 | 踏锋核 | 区段定向 |
| `core_s_bolt` | 主动 | 刃气核 | 区段定向 |
| `core_s_whirl` | 主动 | 旋风核 | 精英 |
| `core_s_smash` | 主动 | 坑冠核 | 领主 |
| `core_a_toughbone` | 被动属性 | 韧骨核 | 小怪低爆 |

## 4. 念力系统

**念力 = 使用技能时消耗的资源**（战斗蓝条），与生命并列显示于 HUD。

| 项 | 定案 |
|----|------|
| 消耗 | 主动技能按表扣念力；念力不足无法释放（普攻不耗） |
| 上限 | 基础值 + **智力**换算 |
| 回复 | 脱战回复（精神影响速率）；战斗中极慢或为 0（表定） |
| 回满 | 城镇休息；念力药剂（商店，贵） |
| 传送 | 入坑锚点 / 局内互传 **也可消耗同一条念力**（初表：入坑锚点 15，局内互传 10，默认出生 0） |

- **废弃**「念力等级」作为独立养成轴。
- 药剂恢复量、脱战回复速率进 `data/mind.json`。

## 5. 敌人韧性（破盾）

敌人除生命外可拥有 **韧性条**（精英 / 特殊怪 / 领主优先；小怪可选）。

| 状态 | 表现 |
|------|------|
| 未破防 | 短硬直；伤害 ×1 |
| 破防 | 韧性归零 → 眩晕约 1.2s；期间受伤 ×1.5；眩晕结束韧性回满 |

锤 / 崩山等技能对韧性有额外系数（表定）。

**工程现状**：横版 `side_enemy` 已有韧性；俯视 `pit_enemy` **未实装**。v3.0 视为必做（阶段 B）。

## 6. 四阶生物与战斗职责

详见 `05`。战斗侧摘要：

| 等级 | 职责 |
|------|------|
| 小怪 | 数量压力，低品阶晶核 |
| 精英 | 区段高威胁，定向材料 + 中高品阶晶核 |
| 特殊怪 | 稀有机制（飞行、隐身、反召唤等），挂钩秘境条件 |
| 领主 | 层 / 区终局，高品阶晶核 + 下层或秘境钥匙类掉落 |

小怪 / 精英头顶显示 HP（破盾时显示韧性）；领主血条在屏幕顶栏。

## 7. 技能树 UI 规则

- 按烙印分系；节点锁定直到消耗合格晶核。
- 可预览未学节点的品阶 / 等级 / 念力需求。
- 学会后拖到热键槽（或在节点上「装配到 Q」）。
- 坑内可学，但**建议**回城在感悟台批量处理（无强制）。
