## 1. 俯视基础操作

| 输入 | 行为 |
|------|------|
| 移动 | WASD / 方向键（八向） |
| 普攻 | 鼠标左键，朝向鼠标短斩（可 2～3 段） |
| 技能 1 | 鼠标右键，释放点 = 鼠标世界坐标 |
| 技能 2～6 | **Q / E / R / F / C**，释放点 = 鼠标世界坐标 |
| 交互 | **空格**（或点击可互动物） |
| 切换堆叠掉落 | 鼠标滚轮 |
| 背包 | Tab / B |
| 属性 | **V** |
| 技能/感悟面板 | K |

**取消**：跳跃、闪避/翻滚、Ctrl 防御（防御技后置，不占热键）。

手感验收（P0）：

1. 走位流畅，攻击/放技能时角色朝向鼠标。  
2. 挥空有重量感（动画 + 顿帧 + 音效）。  
3. 技能落点清晰，冷却可读。

## 2. 烙印 = 武器栏

- 每局生成 **1** 个主烙印，装备在**武器栏**。
- 烙印**类型**限制可学/可装备技能池（大刀 → 仅刀类）。
- MVP：**仅大刀类型**；品质受念力等级权重影响。
- 烙印为**局内存在**：撤离/死亡后消散；**已感悟技能跨局保留**。

### 品质分档

| 品质 | 名称例 | 表现 |
|------|--------|------|
| 普通 | 铁纹 | 基础物攻 |
| 精良 | 铜纹 | 小幅物攻/判定 |
| 稀有 | 银纹 | 轻微特效 |
| 史诗 | 金纹 | 明显特效 |

### 念力等级 → 品质权重（初表）

| 等级 | 普通 | 精良 | 稀有 | 史诗 |
|------|------|------|------|------|
| 1 | 70% | 25% | 5% | 0% |
| 2 | 55% | 35% | 9% | 1% |
| 3 | 40% | 40% | 16% | 4% |
| 4 | 28% | 42% | 22% | 8% |
| 5 | 18% | 40% | 30% | 12% |

## 4. 武器觉醒分支（质变 · MVP 大刀 2 支）

局外用**定向材料**对大刀系进行觉醒（改变技能逻辑，而非只加数字）：

| 分支 | 名称 | 质变方向 | 定向材料来源（草案） |
|------|------|----------|----------------------|
| 甲 | 旋风锋 | 普攻/右键偏 AOE 清怪，更适合沉苔沼群怪 | 沉苔沼精英 / 沼心虫残壳 |
| 乙 | 铁壁反 | 右键/近身偏格挡反击窗口，更适合折铜谷硬敌 | 折铜谷精英 / 甲壳残片 |

- 同时只能激活一条觉醒主分支（可消耗材料切换，成本高）。
- 未觉醒时使用基础大刀普攻/杀招。
- **设计意图**：养成改变操作，并倒逼「去特定危险区段刷定向材料」。

## 5. 晶核与感悟

### 原则

- **晶核**是坑内怪物特有掉落，进背包，计承重。
- **营地感悟台**消耗晶核（+ 可选念力值 / 念力等级门槛）→ 解锁技能或升技能等级。
- **坑内不能学技能**。感悟是学习/养成技能的**唯一**方式。
- 已感悟技能跨局保留；未感悟晶核随背包撤离/死亡规则。
- 感悟后在技能面板把技能拖到右键 / Q / E / R / F / C。

### MVP 晶核池

| ID | 类型 | 名称 | 来源（草案） | 效果 |
|----|------|------|--------------|------|
| `core_s_chain` | 技能 | 连环斩核 | 近战杂兵 | 强化普攻连段与伤害 |
| `core_s_quake` | 技能 | 崩山击核 | 远程杂兵 | 朝鼠标方向砸地/直线高伤 |
| `core_s_dash` | 技能 | 踏锋核 | 区段定向 | 短冲向鼠标（**无无敌帧**） |
| `core_s_bolt` | 技能 | 刃气核 | 区段定向 | 朝鼠标射出刃气 |
| `core_s_whirl` | 技能 | 旋风核 | 精英 | 身周 AOE（与旋风锋觉醒协同） |
| `core_s_smash` | 技能 | 坑冠核 | 层 BOSS | 鼠标落点大范围砸击 |
| `core_a_toughbone` | 属性 | 韧骨核 | 杂兵低爆 | 体力/生命小幅 |
| `core_a_heavyarm` | 属性 | 沉臂核 | 杂兵低爆 | 力量/物攻小幅 |
| `core_a_sharpeye` | 属性 | 锐眼核 | 精英/中层 | 暴击小幅 |
| `core_a_cruel` | 属性 | 狠劲核 | 精英/中层 | 爆伤小幅 |

原横版闪避符文 `rune_s_cloudstep` / 踏云 **废弃**。

### 感悟消耗（初表）

| 档 | 念力值 | 等级门槛 | 晶核 |
|----|--------|----------|------|
| 低（连环斩/踏锋/韧骨/沉臂） | 20 | 1 | 1 |
| 中（崩山/刃气/锐眼/狠劲） | 35 | 2 | 1 |
| 高（旋风/坑冠） | 50 | 3 | 1 |

升技能等级：再消耗同 ID 晶核 + 递增念力值。

## 6. 阶段 A 验收范围

俯视：WASD + 左键朝鼠标普攻 + 右键/Q 至少各 1 个指向技 + 木桩。  
无跳跃、无闪避。不过关不扩展生态与基建。

## 7. 敌人韧性（破盾）

俯视敌人除生命外可拥有 **韧性条**（精英/BOSS 优先）。玩家命中时同时扣除 HP 与韧性：

| 状态 | 表现 |
|------|------|
| 未破防 | 短硬直；伤害 ×1 |
| 破防 | 韧性归零 → 眩晕约 1.2s；期间受伤 ×1.5；眩晕结束韧性回满 |

## 8. 俯视敌人原型（全局共用）

| ID | 名称 | 类型 | 攻击方式 |
|----|------|------|----------|
| 近战杂兵 | 苔刺甲虫等 | 近战 | 接近后短距冲撞 |
| 远程杂兵 | 孢囊射手等 | 远程 | 保持距离，**直线**弹（无重力抛物） |
| 精英 | 各区领卫 | 精英 | 蓄力冲撞 + 近身重砸 |
| BOSS | 坑冠兽 | BOSS | 砸地冲击波 / 连发弹幕 |

- 战斗区混刷普通怪；精英点刷精英；层 BOSS 刷 BOSS。
- 普通怪与精英头顶显示 HP；BOSS 血条在屏幕顶栏。
