# 《巨坑之下》设计文档（现行）

> **本目录为现行设计源。**  
> [`doc/old/`](../old/) 下的 `策划案_MVP.md`、`游戏设定构思.txt`、`《巨坑之下》游戏核心玩法调整.md` 等为**归档参考**；`doc/new` 横版 v1.0 条文已由本 **v2.0** 覆盖。冲突时以本目录为准。

## 品类定案

- **俯视 2D 探索 ARPG** + **营地养成**：每局程序生成第 1 层大地图；WASD + 鼠标指向技能；死亡重开；技能只能在营地用 **晶核感悟**。
- 手感对标火炬之光 2 的走位与指向释放，**不做** 3D 等距。
- 核心循环强调**探索路线 / 侵蚀返航 / 晶核养成 / 基建质变**，而非纯数值刷子。
