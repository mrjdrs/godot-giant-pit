# 07 — 美术质感规范

> 文档族：doc v2.0｜坑内俯视 + Hub 俯视营地  
> 生成脚本：`giant-pit/tools/gen_mvp_pixel_art.py`（legacy 俯视 / UI）  
> 场景氛围：`giant-pit/scripts/fx/scene_atmosphere.gd`

---

## 风格锚点

| 项 | 定案 |
|----|------|
| 大类 | **炼金奇幻卡通像素**（非写实、非纯扁平色块） |
| 轮廓 | `#2A1F18` |
| 炼金青 | `#3D8B7A` |
| 烙印金 | `#E8A838` |
| 视角 | 坑内/战斗：**俯视 2D**；Hub：**俯视 2D** |

目标观感：像素清晰、块面有体积、三区色调可辨，而非「程序矩形占位图」。MVP 角色用 legacy 俯视单图左右翻转，不做完整 8 向套。

---

## 像素与渲染规范

| 规则 | 说明 |
|------|------|
| 前景过滤 | 角色、敌人、道具、地面 tile：**Nearest** |
| 相机 zoom | 玩家 Camera2D **2.5**（整数倍感；勿随意改 collision 尺度） |
| 光源方向 | **固定左上**；所有程序化 shading 统一 |
| 体积 shading | 每个部位 ≥ **基色 / 高光 / 阴影 / 轮廓** 四档 |
| 角色尺寸 | 俯视占位约 **32×32**；tile **32×32** |
| 地面铺设 | **32px tile** 重复 |

---

## 三区调色（CanvasModulate）

| 生态 | preset | 倾向 | 雾尘粒子 |
|------|--------|------|----------|
| 沉苔沼 moss | `(0.88, 0.96, 0.90)` | 偏绿、潮湿 | 孢子、苔屑 |
| 折铜谷 copper | `(0.98, 0.90, 0.82)` | 偏暖、矿锈 | 铜屑、尘粒 |
| 回声廊 echo | `(0.82, 0.86, 1.0)` | 偏紫、冷 | 漂浮光点 |
| Hub 营地 hub | `(1.0, 0.96, 0.88)` | 暖石、炉火感 | 少而弱 |

进入生态时更新 `SceneAtmosphere.set_biome()`。迷雾用 chunk 遮罩，禁止纯 ColorRect 当主视觉（可用半透明 tile）。

---

## 场景层次（由远到近）

1. **CanvasModulate** — 全区色调  
2. **地面 / 墙** — tile 重复  
3. **迷雾 chunk**  
4. **实体** — 玩家、敌人、交互物、掉落  
5. **轻暗角** — `vignette.gdshader`，强度默认 **0.22**

Hub：暖色 modulate + 砖缝 floor + 像素墙 tile。

---

## 禁止项

- 小图暴力 `scale` 当全屏背景
- 纯 `ColorRect` 作为雾/泥/背景主视觉
- 无明暗的单色块角色/敌人
- 前景使用 Linear 过滤
